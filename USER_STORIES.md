# Veridrop — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Network operator

- As a network operator, I want rewards gated on accepted proofs, so that upload spam cannot drain the emission schedule.
- As a network operator, I want to pause emission for a compromised proof type, so that an exploit does not empty the treasury overnight.
- As a network operator, I want versioned bonding-curve parameters, so that economic changes are auditable.

### Keeper / service provider

- As a keeper, I want to submit availability proofs for assets I host, so that I can earn rewards tied to real delivery.
- As a compute provider, I want to attach integrity proofs to privacy-preserving jobs, so that buyers accept results without seeing raw inputs.
- As a provider, I want clear slash reasons when a proof is rejected, so that I can remediate rather than guess.

### Curator / staker

- As a curator, I want to stake into drops on an asset I believe will be used, so that correct prediction is rewarded.
- As a curator, I want to un-stake under published rules, so that capital is not permanently trapped without notice.

### Marketplace integrator

- As a marketplace integrator, I want to read proof and stake signals per asset, so that my catalogue can rank by verified relevance rather than self-reported quality.

### Auditor / arbitrator

- As an auditor, I want a full proof and reward trail for a period, so that I can attest incentive integrity to the foundation board.
- As an arbitrator, I want dispute outcomes to update entitlement and reward eligibility, so that IP theft claims have teeth.
